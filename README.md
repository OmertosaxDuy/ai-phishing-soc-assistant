# AI Phishing SOC Assistant - Week 1

Dự án khởi đầu để phân tích email và trích xuất các chỉ báo xâm nhập (IOC)
như URL, địa chỉ email và địa chỉ IP.

## Cài đặt

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

## Chạy ứng dụng

```bash
python app.py
```

## Chạy kiểm thử

```bash
pytest
```
